# How the fixer works

The fixer is a Python controller around Claude Sonnet 4.6 with local investigation and repair tools. It runs original public tests and simulator seeds, discovers healthy public scenario/profile controls, and retrieves bounded current contracts. Optional Jev decisions filter weak document matches while preserving authoritative evidence and uncertain results.

Sonnet records source-bound hypotheses, examines causal trace windows, composes immutable fault probes, and edits a staged source tree with captured repair intent. Measured replay costs select additional coverage within the deadline. Public seeds, explicit probes, earlier passing experiments and every previously repaired obligation remain mandatory. Acceptance requires tests, reproduced progress, preserved obligations and deterministic repeats. A separate native Sonnet review receives exact matched inputs and complete changed/related protocol bodies. Typed blockers carry evidence references; partial fixes require review.

Accepted patches are installed, checked again, and rolled back on verification failure. Source hashes and Python compilation reject stale or malformed edits. Spend reservations and bounded subprocesses protect final verification. Compaction preserves source-bound findings, repair intent and complete tool exchanges. Cached replays count as information; new executions establish progress. Six information turns can trigger validation or an immutable diagnostic. Bounded configuration previews and failed-attempt corrections support a second explicit probe construction. Diagnostics retain the prior rejection. Cancellation stops local workers.
