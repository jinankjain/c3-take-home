# How the fixer works

The fixer is a Python controller around Claude Sonnet 4.6. It runs original public tests and simulator seeds, discovers healthy public scenario/profile controls, and retrieves current contracts. Optional Jev filtering preserves authoritative evidence and uncertain results.

Sonnet records source-bound hypotheses, inspects causal traces, composes immutable probes and edits staged source with captured intent. Public seeds, probes, earlier passing controls and repaired obligations remain mandatory. Acceptance requires tests, reproduced progress, preserved obligations and deterministic repeats. Native review receives matched inputs and bounded complete source bodies, including protocol producers and runtime writers. Partial fixes require valid review.

Accepted patches are installed, verified and rolled back on failure. Source hashes, compilation, cancellable subprocesses and spend reserves protect that process. Compaction retains findings, intent and native exchanges; cached replays count as information. Stalls can trigger validation or bounded probes with construction feedback. One resource-protected independent diagnosis can explain a matched passing-control regression; its advice cannot authorize promotion or change the rejection.
